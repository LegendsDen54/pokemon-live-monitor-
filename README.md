# Pokémon Drop Monitor

This is the installable iPhone PWA frontend.

Current behavior:
- Target/Walmart UI
- direct-retailer seller filter
- <=150% MSRP rule
- 30th Anniversary priority treatment
- one-tap retailer handoff
- browser notification permission
- Home Screen/PWA support

Important: the included products are demo records. Live retailer inventory requires an authorized retailer data source and a continuously running backend. The app deliberately stops at the retailer checkout handoff; it does not store payment credentials or automatically submit real orders.
